# Aksjeagent for ASK

Agent som følger Kristines aksjesparekonto og Oslo Børs med Warren Buffetts metode.

| Fil | Innhold |
|---|---|
| `INSTRUKS.md` | Hva agenten gjør søndag og på hverdager |
| `metode.md` | Buffett-kriterier, fair P/E = 8,5 + 2G, avkastningsformelen, salgsregler |
| `etikk.md` | Utelukkede bransjer og gråsoner |
| `portefolje.json` | Beholdning, antall og GAV |
| `beslutningslogg.md` | Hva Kristine har valgt hver uke (agentens hukommelse) |
| `kandidater.md` | Kjøpskandidater som bæres videre fra uke til uke |
| `varsellogg.md` | Hastevarsler og hendelser på hverdager |
| `analyser/` | Én fil per selskap, oppdateres løpende |
| `ukesrapporter/` | Arkiv av søndagsrapportene |

## Kjøreplan (norsk tid)
- Søndag ca. 20:00: ukesrapport med anbefalinger for mandag
- Mandag–fredag ca. 08:00 og 16:45: stille sjekk av porteføljen, varsel bare hvis det haster
